## Hockey-Position-Classifier
Class Project for DS 110 Introduction to Data Science with Python

## Description
Compares Random Forest Classifier, Decision Trees, and K-Nearest Neighbors in effectiveness in classifying hockey players by position using their season stats.
Data can be also be used to see the details of the game that differentiate players the most and attempt to find trends in position data over time. 

## Future Additions
Can find outliers in the data to see skaters that might fit into other positions the best, especially useful for finding centers that can play wing and vice versa.
